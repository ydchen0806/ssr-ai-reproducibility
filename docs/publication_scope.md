# Release scope

This repository contains the AI experiments referenced by the current main text and supplementary material. Generic mathematical dependencies and attributed upstream source are included where needed to execute those experiments. Meeting notes, editorial drafts, cluster job submissions, abandoned experiment branches and unrelated benchmark reports are not part of the release.

Data S1 is synchronized to the current manuscript displays and supplementary analyses. The prior release and its broader recorded-cohort files remain available through Git history; corresponding original command records and checkpoint archive links remain indexed separately. Source hashes, seeds and original recorded commands are scientific provenance and are intentionally retained.
