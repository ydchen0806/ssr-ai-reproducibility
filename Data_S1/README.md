# Data S1: computational figure source data

MANIFEST.csv lists every delivered file, its panel, original source location and SHA-256 checksum. Original paths identify provenance; the delivered relative paths are portable. DISPLAYED_SEEDS.csv and figure5_panel_sources.json map each panel to its evaluated cohort.

Figure 4A uses the September 30 collaborator artwork. B/E report five paired seeds per dataset. C uses ten training seeds on one fixed sequence. D uses ten paired seeds. F displays seven arms from ten paired orders. G is one full-recipe pair per setting, and I is four geometry pairs per dataset. H shows ten paired AlphaEdit orders as vertical bars. Whiskers are 95% Student-t intervals of each mean; Table S6 reports the paired bootstrap intervals of the gains. Six earlier efficacy checkpoints remain in the raw records but are not plotted. See figure4/COHORT_REGISTRY.md.

Figure 5 uses 32-target rehearsal. Rank 32 uses orders 26092711-26092719 and 26092721. Rank 8 uses orders 26092711-26092720. figure5_dual_followup supplies A, B, E and the rank-8 and rank-32 positions in C and D. figure5_rank1664_followup supplies the rank-16 positions in C and D. The rank-32 trajectory is computed from those displayed rank-32 records. This release contains those displayed cohorts only.

Figure 4B--F and H use final-history efficacy and locality. G reports the recorded endpoints for each example after 100 edits. Figure 5A--E show WikiRecent immediate and history readouts under 32-target rehearsal. These cohorts are not interchangeable. Figure 6 CUB/CIFAR AA and AF use final task-history scores; VOC reports stage-wise and final-stage segmentation scores.

Figure 4F displays seven arms. Table S2 uses the Figure 4B/E seed sets. Figure 6F and the supplementary strength figure both display all nine strengths.
